# 🎙️ Pragna Vaani (ಪ್ರಜ್ಞಾ ವಾಣಿ)
## Voice of Wisdom - Kannada Speech Recognition

A powerful offline Kannada speech recognition system using the SraVaani-1.0 model from ARTPARK-IISc.

## 🎯 Features

- 🎤 **High Accuracy** - State-of-the-art FastConformer model
- 🔥 **65+ Indian Languages** - Kannada, Hindi, Tamil, Telugu, Malayalam, and more
- 💻 **100% Offline** - Works without internet after first download
- ⚡ **Fast** - Real-time transcription on CPU
- 🎵 **Multiple Formats** - Supports M4A, MP3, FLAC, WAV (auto-converts)

## 📋 Prerequisites

- Python 3.10+
- 15GB free disk space
- FFmpeg (for audio conversion)
